# Смены менеджеров

Учёт рабочих дней Хеды и Камилы. Утром в группу WhatsApp уходит опрос
«Кто сегодня на смене?», выбор подтверждается и попадает в базу.

Своего сервера нет: страница ходит в Green API напрямую из браузера
(CORS у Green API открыт), данные лежат в mokky.dev.

```
index.html          календарь и итоги, только просмотр
admin.html          админка: календарь, менеджеры, выплаты, опрос, журнал
assets/config.js    ключи — единственный файл, который нужно заполнить
assets/bot.js       отправка опроса по расписанию и разбор выборов
data/mokky-seed.json  начальное содержимое базы
data/legacy-workdays.json  архив 177 записей старого трекера
```

## Настройка

### 1. База

В панели mokky.dev вставьте содержимое `data/mokky-seed.json`. Это разом
создаёт нужные коллекции и очищает старые данные (архив уже сохранён в
`data/legacy-workdays.json`).

### 2. Ключи

В `assets/config.js` заполните:

- `MOKKY_URL` — адрес инстанса mokky
- `GREEN_ID` — `idInstance` из личного кабинета Green API
- `GREEN_TOKEN` — `apiTokenInstance`
- `GREEN_API_URL` — хост вашего инстанса, например `https://7107.api.greenapi.com`

### 3. Green API

Откройте админку → вкладка **Опрос** → **Проверить**. Кнопка «Исправить
настройки» выставит всё нужное сама. Что именно проверяется:

| Параметр | Значение | Зачем |
|---|---|---|
| `webhookUrl` | пусто | иначе `receiveNotification` вернёт ошибку |
| `pollMessageWebhook` | `yes` | **по умолчанию `no`** — без него выборы не придут |
| `incomingWebhook` | `yes` | приём входящих |
| `enableLidMode` | `no` | иначе вместо номеров придут `@lid` и белый список сломается |

Номер, привязанный к инстансу, должен состоять в группе.

### 4. Менеджеры и группа

- Вкладка **Менеджеры** — впишите телефоны Хеды и Камилы. Без телефона их
  выбор в опросе не засчитывается.
- Вкладка **Опрос** → «Показать мои группы» → выберите нужную → «Сохранить».
- Там же смените PIN входа (по умолчанию `1234`).

## Кто может отмечать

WhatsApp не умеет ограничивать, кто голосует в групповом опросе — это может
любой участник. Фильтр работает на нашей стороне: в вебхуке приходит список
номеров проголосовавших, и засчитывается только выбор с телефонов менеджеров
и номеров из поля «Дополнительные номера». Всё остальное попадает в журнал с
пометкой «отклонён».

## Подтверждение выбора

Настраивается на вкладке **Опрос**:

- **Вторым опросом** (по умолчанию) — после выбора приходит «✅ Подтверждаю /
  ❌ Отменить», запись создаётся только после подтверждения. Случайный тап в
  базу не попадает.
- **Отложенно** — записывается через N минут, если выбор не менялся.
- **Сразу** — без подтверждения.

## Вечернее напоминание

В 21:00 (вкладка **Опрос**) в группу уходит «Завтра смена Хеды — 17.09» с
вариантами «✅ Смогу / ❌ Не смогу». Кто завтра на смене, бот считает по
истории: менеджеры работают по два дня подряд, после двух дней — следующий.

- «Не смогу» → второй опрос второму: «Завтра смена Хавы — 17.09 (Хеда не
  сможет)» с «✅ Приду / ❌ Тоже не смогу».
- «Тоже не смогу» → сообщение «⚠️ Завтра на смену никто не выходит».

Засчитывается только голос того, кому адресован опрос, и дополнительные номера.
Вечерние опросы — просто напоминание: в дни, выплаты и журнал не попадают и
уборкой не удаляются. В настройках хранится лишь метка последнего напоминания
(`evening`), чтобы не отправить его дважды. Проверить: `/api/cron?evening=1`.

## Уборка в группе

Чтобы чат не зарастал опросами, бот удаляет их за собой после фиксации дня.
Настраивается на вкладке **Опрос**:

- **Оставлять итог** (по умолчанию) — оба опроса и служебные сообщения
  («⏳ Принято», «❌ Отменено») удаляются, остаётся одна строка
  «✅ Зафиксировано: Хеда — 01.09».
- **Удалять всё** — не остаётся даже итога.
- **Ничего не удалять**.

Удаление отложенное — по умолчанию через 10 секунд, чтобы все успели увидеть
результат. Срок хранится в базе, а не только в таймере вкладки: если вкладку
закроют раньше, уборку доделает следующая.

WhatsApp разрешает удалять сообщения у всех участников 72 часа после отправки —
бот укладывается в это окно с большим запасом. История дней и выборов остаётся
в mokky независимо от того, что удалено в чате.

## Два режима приёма выборов

Green API умеет отдавать выборы двумя способами, и они **взаимоисключающие** —
как только в настройках инстанса задан `webhookUrl`, метод `receiveNotification`
начинает отвечать ошибкой.

### Вебхук (мгновенно) — рекомендуется

Green API сам стучится в функцию на Vercel в момент голосования, задержка —
доли секунды, компьютер выключен. Так работают `api/webhook.js` и `api/cron.js`.

Развернуть:

1. На vercel.com импортировать этот репозиторий (Add New → Project). Сборка не
   нужна, настройки по умолчанию подходят.
2. Прописать в Green API адрес вебхука:
   `https://<проект>.vercel.app/api/webhook` — параметр `webhookUrl`.
3. Проверить: открыть `https://<проект>.vercel.app/api/cron` — вернётся текущее
   время, время отправки и группа. `?force=1` отправит опрос немедленно.

Ключи берутся из `assets/config.js`. Если захотите их оттуда убрать, задайте в
настройках проекта Vercel переменные `MOKKY_URL`, `GREEN_ID`, `GREEN_TOKEN`,
`GREEN_API_URL` — приоритет у них. Необязательные: `WEBHOOK_TOKEN` (тогда тот же
токен пропишите в Green API как `webhookUrlToken`) и `CRON_SECRET`.

### Опрос очереди (с задержкой)

Работает, пока `webhookUrl` пуст. Тогда выборы копятся в очереди Green API, и
её вычитывает открытая вкладка сайта или локальный запуск `npm run bot`.
Выборы не теряются — очередь живёт 24 часа, — но обрабатываются только в момент
тика, то есть с задержкой. Вернуться в этот режим можно в любой момент, очистив
`webhookUrl`.

Бот распознаёт режим сам и, увидев отключённую очередь, перестаёт её трогать,
оставляя за собой только расписание и уборку.

## Чем слать утренний опрос

Отправка опроса — исходящий вызов, она работает в обоих режимах. Повесить её
можно сразу на несколько источников: замок в mokky не даст отправить дважды.

| Источник | Точность | Настройка |
|---|---|---|
| Vercel cron | в пределах часа | уже настроено |
| cron-job.org на `/api/cron` | до минуты | 2 минуты, бесплатно |
| Открытая вкладка | секунды | ничего |

Час — ограничение бесплатного тарифа Vercel, и оно касается **только** момента
отправки опроса. На приём выбора не влияет: вебхук срабатывает мгновенно
независимо от того, чем был отправлен опрос.

## Локальный запуск бота

`npm run bot` (он же `node bot/tick.cjs`) — тот же код, что крутит вкладка:
скрипт подгружает файлы из `assets/` и зовёт `Bot.tick()`. Нужен, если вы
вернётесь к режиму очереди или захотите разобрать её вручную. По умолчанию
работает 240 секунд, меняется переменной `RUN_SECONDS`.

Ключи берёт из `assets/config.js`, но их можно переопределить переменными
окружения `MOKKY_URL`, `GREEN_ID`, `GREEN_TOKEN`, `GREEN_API_URL`.
