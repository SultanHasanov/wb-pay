# Смены менеджеров

Учёт рабочих дней Хеды и Камилы. Утром в группу WhatsApp уходит опрос
«Кто сегодня на смене?», выбор подтверждается и попадает в базу.

Своего сервера нет: страница ходит в Green API напрямую из браузера
(CORS у Green API открыт), данные лежат в mokky.dev.

```
index.html          календарь и итоги, только просмотр
admin.html          админка: календарь, менеджеры, выплаты, опрос, журнал
assets/config.js    ключи — единственный файл, который нужно заполнить
assets/bot.js       отправка опроса по расписанию и разбор выборов
data/mokky-seed.json  начальное содержимое базы
data/legacy-workdays.json  архив 177 записей старого трекера
```

## Настройка

### 1. База

В панели mokky.dev вставьте содержимое `data/mokky-seed.json`. Это разом
создаёт нужные коллекции и очищает старые данные (архив уже сохранён в
`data/legacy-workdays.json`).

### 2. Ключи

В `assets/config.js` заполните:

- `MOKKY_URL` — адрес инстанса mokky
- `GREEN_ID` — `idInstance` из личного кабинета Green API
- `GREEN_TOKEN` — `apiTokenInstance`
- `GREEN_API_URL` — хост вашего инстанса, например `https://7107.api.greenapi.com`

### 3. Green API

Откройте админку → вкладка **Опрос** → **Проверить**. Кнопка «Исправить
настройки» выставит всё нужное сама. Что именно проверяется:

| Параметр | Значение | Зачем |
|---|---|---|
| `webhookUrl` | пусто | иначе `receiveNotification` вернёт ошибку |
| `pollMessageWebhook` | `yes` | **по умолчанию `no`** — без него выборы не придут |
| `incomingWebhook` | `yes` | приём входящих |
| `enableLidMode` | `no` | иначе вместо номеров придут `@lid` и белый список сломается |

Номер, привязанный к инстансу, должен состоять в группе.

### 4. Менеджеры и группа

- Вкладка **Менеджеры** — впишите телефоны Хеды и Камилы. Без телефона их
  выбор в опросе не засчитывается.
- Вкладка **Опрос** → «Показать мои группы» → выберите нужную → «Сохранить».
- Там же смените PIN входа (по умолчанию `1234`).

## Кто может отмечать

WhatsApp не умеет ограничивать, кто голосует в групповом опросе — это может
любой участник. Фильтр работает на нашей стороне: в вебхуке приходит список
номеров проголосовавших, и засчитывается только выбор с телефонов менеджеров
и номеров из поля «Дополнительные номера». Всё остальное попадает в журнал с
пометкой «отклонён».

## Подтверждение выбора

Настраивается на вкладке **Опрос**:

- **Вторым опросом** (по умолчанию) — после выбора приходит «✅ Подтверждаю /
  ❌ Отменить», запись создаётся только после подтверждения. Случайный тап в
  базу не попадает.
- **Отложенно** — записывается через N минут, если выбор не менялся.
- **Сразу** — без подтверждения.

## Уборка в группе

Чтобы чат не зарастал опросами, бот удаляет их за собой после фиксации дня.
Настраивается на вкладке **Опрос**:

- **Оставлять итог** (по умолчанию) — оба опроса и служебные сообщения
  («⏳ Принято», «❌ Отменено») удаляются, остаётся одна строка
  «✅ Зафиксировано: Хеда — 01.09».
- **Удалять всё** — не остаётся даже итога.
- **Ничего не удалять**.

Удаление отложенное — по умолчанию через 10 секунд, чтобы все успели увидеть
результат. Срок хранится в базе, а не только в таймере вкладки: если вкладку
закроют раньше, уборку доделает следующая.

WhatsApp разрешает удалять сообщения у всех участников 72 часа после отправки —
бот укладывается в это окно с большим запасом. История дней и выборов остаётся
в mokky независимо от того, что удалено в чате.

## Кто крутит бота

Логика бота одна, а запускать её могут двое:

**Открытая вкладка сайта.** Пока страница открыта, она тикает сама. Если вкладок
несколько, работает только одна — ведущая выбирается замком в `localStorage`.

**GitHub Actions** — `.github/workflows/bot.yml`, каждые 5 минут запускает
`bot/tick.cjs`. Это тот же код: скрипт подгружает файлы из `assets/` и зовёт
`Bot.tick()`, поэтому логика не дублируется. Работает без открытого браузера.

Одновременная работа обоих безопасна: отправку опроса защищает замок в mokky,
а очередь Green API отдаёт каждое уведомление только один раз.

Оговорки по Actions:

- минимальный интервал — 5 минут, и GitHub нередко задерживает запуск ещё на
  5–15 минут, так что опрос придёт в интервале 09:00–09:15, а не ровно в 09:00;
- на публичных репозиториях расписание отключается после 60 дней без коммитов —
  нужен любой коммит раз в пару месяцев (GitHub присылает предупреждение);
- минуты для публичных репозиториев бесплатны и не лимитированы.

Ключи скрипт берёт из `assets/config.js`. Если захотите убрать их из репозитория,
заведите секреты `MOKKY_URL`, `GREEN_ID`, `GREEN_TOKEN`, `GREEN_API_URL` —
workflow их уже прокидывает, а в файле оставьте заглушки `REPLACE_ME`.

Запустить локально: `node bot/tick.cjs` (по умолчанию крутится 240 секунд,
меняется переменной `RUN_SECONDS`).

## Что остаётся неизменным

Выборы не теряются, даже если ничего не запущено: очередь Green API хранит
уведомления 24 часа, и всё непрочитанное разберётся при следующем запуске —
хоть вкладкой, хоть Actions.
